# Litigation Finance News Analyzer Skill

이 스킬은 소송금융 투자 적합성을 판단하기 위해 뉴스 기사를 자동으로 분석하는 프로세스를 안내합니다.

> **Note**: 이 스킬은 로컬 환경에서 실행되도록 설계되었으며, 별도의 서버 배포나 프로덕션 환경 구성은 필요하지 않습니다.

## 🎯 목적

소송금융 투자를 검토하는 심사역의 관점에서 뉴스 기사를 분석하여:
- 투자 적합도 등급 (High/Medium/Low) 판단
- 핵심 사건 정보 추출 (사건 분야, 상대방, 피해 규모 등)
- 소송 진행 단계 파악

## 📋 페르소나

**"소송금융 투자를 검토하는 심사역"**
- **원칙적인 법률 전문가**: 법적 타당성과 증거 확보 가능성을 엄격히 검토
- **공격적인 비즈니스 전략가**: 수익성 있는 투자 기회를 적극적으로 포착

## 🔍 분석 프로세스

### 1단계: 뉴스 수집

네이버 뉴스 검색 API를 사용하여 다음 키워드로 기사를 수집합니다:

**필수 키워드 (OR 조건)**:
- 소송
- 손해배상
- 집단소송
- 공동소송
- 피해자
- 피해보상
- 피해구제

### 2단계: 소송금융 적합도 판단

#### 적합 조건 체크리스트

각 기사에 대해 다음 조건들을 평가하세요:

| # | 조건 | 평가 기준 |
|---|------|----------|
| 1 | **상대방 책임이 비교적 명확함** | 기사에서 잘못을 저지른 주체가 구체적으로 특정되는가? |
| 2 | **상대방에게 자력이 충분함** | 대기업, 금융기관, 보험사, 상장회사, 공공기관 등 배상 능력이 충분한가? |
| 3 | **집단적 피해** | 동일 원인으로 다수(수십 명 이상)가 피해를 입었는가? |
| 4 | **피해 규모가 큼** | 피해 금액이 크거나(수억 원 이상), 피해자 수가 매우 많은가(수만 명 이상)? |
| 5 | **증거가 있거나 확보 가능함** | 공식 조사 결과, 정부 발표, 내부 문서 유출 등 객관적 증거가 존재하는가? |
| 6 | **이미 공적 절차가 진행 중임** | 검찰 수사, 정부 조사, 행정처분 등이 진행 중인가? (단, 이미 소송 중인 경우는 제외) |

#### 부적합 조건 체크리스트

| # | 조건 | 평가 기준 |
|---|------|----------|
| 1 | **이미 종결된 사건** | 합의 완료, 판결 확정 등으로 더 이상 다툴 여지가 없는가? |

#### 등급 판정 기준

**High (높음)**:
- 적합 조건 중 **4개 이상** 해당
- 부적합 조건에 **해당 없음**
- 기타 소송금융 투자 가능성이 높은 경우

**Medium (중간)**:
- 적합 조건 중 **2~3개** 해당
- 부적합 조건에 **해당 없음**

**Low (낮음)**:
- 적합 조건 중 **1개 이하** 해당
- 또는 적합 조건 2개 이상이라도 부적합 조건 **1개 이상** 해당
- 기타 소송금융 투자가 어려운 이유가 있는 경우

### 3단계: 사건 분야 분류

기사 내용을 기반으로 적절한 분야를 선택하거나 새로운 분류를 생성하세요:

| 사건 분야 | 설명 | 예시 |
|----------|------|------|
| **제조물책임** | 제품 결함으로 소비자 피해 | 자동차 결함, 가습기 살균제 |
| **산업재해** | 작업 중 안전사고 | 중대재해, 직업병 |
| **환경** | 오염물질 등으로 인한 피해 | 수질 오염, 대기 오염 |
| **소비자분쟁** | 허위광고, 부당계약 등 | 과대광고, 소비자 기만 |
| **노동** | 임금체불, 부당해고 등 | 체불 임금, 부당노동행위 |
| **개인정보** | 개인정보 유출, 무단 수집·이용 | 해킹, 정보 유출 |
| **행정** | 정부·지자체의 위법한 처분이나 부작위 | 행정처분 취소 소송 |
| **건설·부동산** | 부실시공, 분양 사기, 재개발 분쟁 | 층간소음, 하자보수 |
| **지식재산권** | 특허·상표·저작권 침해 | 특허 침해, 저작권 위반 |

### 4단계: 상대방 특정

소송 가능한 대상을 명확히 파악하세요:
- 기업명 (예: "삼성전자", "현대자동차")
- 기관명 (예: "서울시", "금융감독원")
- 복수의 상대방이 있을 경우 모두 나열

### 5단계: 피해 규모 추정

#### 금액 추정
- 기사에 명시된 금액을 우선 사용
- 명시되지 않은 경우 "추정 불가" 또는 유사 사례 기반 추정

#### 피해자 수
- 정확한 수치가 있으면 기재
- 추정치가 있으면 "약 ○○명" 형식으로 기재
- 불명확하면 "다수" 또는 "추정 불가"

### 6단계: 진행 단계 파악

#### 5-1. 진행 단계 (주 단계)

| 단계 | 설명 |
|------|------|
| **피해 발생** | 피해 사실만 보도되었고 아직 법적 조치 없음 |
| **관련 절차 진행** | 검찰 수사, 경찰 수사, 감독기관 조사, 행정처분이 진행 중이거나 완료됨 |
| **소송중** | 피해자가 손해배상 소송을 법원에 제기함 |
| **판결 선고** | 1심/2심 판결이 나오거나 가처분 결과가 나옴 |
| **종결** | 판결 확정, 3심(대법원) 판결, 합의 완료 등 사건 종결 |

#### 5-2. 진행 단계 상세

구체적인 진행 상황을 기재:
- 예: "보상안 논의 중"
- 예: "공정위 과징금 부과"
- 예: "가처분 기각"
- 예: "검찰 기소"

### 7단계: 요약 작성

**2-3문장**으로 다음 내용을 포함하여 요약:
1. 무슨 사건인가?
2. 피해 규모는?
3. 현재 진행 상황은?

## ⚠️ 주의사항

1. **객관성 유지**: 기사 내용에 근거하여 판단하되, 추측이나 가정은 명확히 구분
2. **증거 중시**: 공식 발표, 조사 결과 등 객관적 증거를 우선 고려
3. **자력 확인**: 상대방의 배상 능력이 충분한지 반드시 확인
4. **종결 사건 제외**: 이미 합의나 판결로 종결된 사건은 Low 등급으로 판정
5. **진행 중인 소송**: 이미 소송이 진행 중인 경우, "공적 절차 진행 중" 조건에 해당하지 않음

## 🔄 워크플로우

1. **키워드 검색** → 네이버 뉴스 API 호출
2. **기사 수집** → 검색 결과 파싱 및 저장
3. **적합도 평가** → 6가지 적합 조건 체크
4. **정보 추출** → 사건 분야, 상대방, 피해 규모 등 파악
5. **단계 파악** → 진행 단계 확인
6. **요약 작성** → 2-3문장 요약
7. **JSON 생성** → 구조화된 결과 출력
8. **결과 저장** → 로컬 파일(JSON)로 저장

## 🛠️ 구현 가이드

### API 연동

```python
import requests
import os

def search_naver_news(keyword, display=10):
    """네이버 뉴스 검색 API 호출"""
    client_id = os.getenv('NAVER_CLIENT_ID')
    client_secret = os.getenv('NAVER_CLIENT_SECRET')
    
    url = "https://openapi.naver.com/v1/search/news.json"
    headers = {
        'X-Naver-Client-Id': client_id,
        'X-Naver-Client-Secret': client_secret
    }
    params = {
        'query': keyword,
        'display': display,
        'sort': 'date'  # 최신순
    }
    
    response = requests.get(url, headers=headers, params=params)
    return response.json()
```
